# Code of Conduct

## Our Standard

This project aims to be a respectful, technically serious, and collaborative open-source space. Contributors are expected to communicate clearly, disagree professionally, and focus on improving the software rather than escalating personal conflict.

Examples of expected behavior:

- being respectful in technical discussions
- giving actionable, evidence-based feedback
- assuming good intent while still holding a high quality bar
- accepting correction when presented with clear technical evidence
- helping keep the project approachable for new contributors

Examples of unacceptable behavior:

- harassment, intimidation, or personal attacks
- dismissive or hostile communication
- discriminatory language or behavior
- deliberately derailing technical discussion
- publishing private information without permission

## Scope

This Code of Conduct applies to:

- project discussions
- issue threads
- pull requests
- review comments
- any public or private project spaces used for collaboration

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that violate this Code of Conduct.
